# Rental Manager Android

Android-клиент подключается к существующей FastAPI-панели через JSON API и рисует собственный нативный интерфейс:

- настройка адреса сервера прямо в приложении, чтобы миграция хоста не требовала новой сборки;
- тёмный нативный интерфейс с разделами «Пульт», «Дела», «Оплаты», «Объекты» и «Ещё»;
- дашборд, жильцы, аренда, ручные оплаты, счётчики, коммуналка, тарифы, расходы, отчёты, сообщения и базовые серверные настройки;
- загрузка Excel/JSON-отчётов через системный DownloadManager;
- фоновые проверки `/api/bootstrap` через JobScheduler;
- детальные настройки уведомлений: частота, тихие часы, звук/вибрация/тихо и отдельные типы событий;
- постоянное уведомление по квартирам-должникам без отсрочки.
- проверка обновлений при запуске, возвращении в приложение (не чаще раза в час) и в фоне примерно раз в 6 часов; автоматическое скачивание по Wi-Fi и мобильной сети, без роуминга;
- проверка SHA-256, размера, версии, package и подписи скачанного APK; установка через системное подтверждение Android. В меню «Обновления приложения» можно отключить автоматическую загрузку или проверить вручную.

Публикация APK и канала обновлений: [Android release](../../docs/ANDROID_RELEASE.md). Старую версию 0.1.7 нужно один раз обновить вручную до версии с новым механизмом. План переработки: [этапы](../../docs/ANDROID_REWORK_PLAN.md).

Сборка:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

Готовый APK появляется здесь:

```text
android/RentalManager/build/rental-manager-mobile.apk
android/RentalManager/build/rental-manager-mobile-0.1.8.apk
```

По умолчанию приложение подключается к `https://menedzer-arendy-g33ka.waw0.amvera.tech`. Если в старой установке был сохранён `127.0.0.1` или `localhost`, новая версия автоматически заменит его на публичный адрес.
